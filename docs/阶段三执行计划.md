## 1. 目标与不可变口径

主线为 CWRU→PU，按零目标标注→旧 K19→新 GG K19→K116 拟合参照展开。优先检验物理输入、选标、源多域方法及晚期融合是否改善健康类和未见轴承错误，不预设成功。

- 深度主体仍为 MSRS-ABiLSTM：仅允许第一层输入通道从 1 改为 2，四类头、其余层及 256 维嵌入不改。
- 类顺序固定 `Normal/Ball/IR/OR = 0/1/2/3`。无 Ball 专属阈值、拒识、目标先验掩码或置信度重写。E2 排除 Ball 是评分分解，不改变 E1 预测器。
- 窗口四维概率→记录等权平均→单元内记录等权平均，最后才 argmax；不先投票或混淆窗口/记录权重。数值同分按原类序取最前者。
- PU 主判据仍为全 116 单元的 **E1≥80% 且 E2≥90%**。E1 是四类 argmax 后 N/IR/OR 三类召回的宏平均；E2 将聚合概率的 Ball 项置零，再在 `[0,2,3]` 中全员重判，宏平均类别及样本分母相同。
- `P_ball` 是四类 E1 判 Ball 的单元比例；E1/E2、各类支持数/召回、混淆矩阵、记录级结果与损伤/工况分组并报。缺类子集按现有“有支持类别”宏平均并显式列类别，空组为无可评估样本。
- 监督臂的全体 116 指标仅是含训练单元的描述统计；泛化结论只在各臂自然留出及共同留出下提出。K116 没有泛化留出，不纳入监督泛化曲线。
- 不确定标记不改预测、不删样本、不改 E1/E2 分母。高置信子集结果另报覆盖率，不叫主准确率。
- 75% 文献锚只作非同协议 E2 参考；本轮是看过阶段二错误结构后的迭代基准，不是新盲测。12 个源折/seed 格不是 12 个独立目标测试集。

### 2.1 轴承频率与转速

故障来源轴承与观测测点分开：`12k_DE/48k_DE` 的两传感器都用驱动端故障几何；`12k_FE` 的两传感器都用风扇端故障几何；Normal 按测点对应的轴承候选计算。来源位置是已知试验元数据，不是诊断类别；禁止按 N/B/IR/OR 标签、严重度或损伤来源更改提取公式。

| 物理候选 | BPFO | BPFI | BSF（不是 2BSF） | FTF |
| --- | ---: | ---: | ---: | ---: |
| CWRU DE | 3.5848 | 5.4152 | 2.3572 | 0.3983 |
| CWRU FE | 3.0530 | 4.9470 | 1.993557418 | 0.381625 |

表中数值乘转频 Hz。DE 沿用 v1 常数；FE 按 8 球、接触角 0，由已记录的 BPFO=3.0530 派生：`r=1-2*BPFO/8=0.23675`，`BPFI=4*(1+r)`、`BSF=(1-r*r)/(2*r)`、`FTF=(1-r)/2`。这不是新增官网核验；历史 `3.9874` 约对应 2BSF，不再当 BSF 混用。事实表记录上述来源与解析假设。

PU 使用既有逐轴承节径，`Z=8,d=6.75mm,α=0,r=d/D`：`BPFO=Z*(1-r)/2`、`BPFI=Z*(1+r)/2`、`BSF=(1-r*r)/(2*r)`、`FTF=(1-r)/2`；工况转频仍为 N15=25Hz、N09=15Hz，不根据谱峰回估。

CWRU 先按现有特殊键规则选择信号前缀，再读取该前缀的 `RPM` 或 `_RPM` 标量字段；若匹配字段不唯一、非有限或非正则报错。确实缺失时按文件末尾载荷档 `[0,1,2,3]` 回退 `[1797,1772,1750,1720] rpm`，逐条记录回退，不借用其他前缀 RPM。转频为 RPM/60；不改变 v7 信号键选择。

## 3. 固定输入配方与缓存

### 3.1 两支路的窗口

原记录按精确有理数比 `resample_poly` 重采样至 12kHz 一次。logspec 保持 **512/512、无重叠**，末尾不足一窗丢弃；原 v7 的 `reshape(n,512)`、特征数值及窗数都保留。

物理包络使用 **2048/1024、50% 重叠**，仅取完整窗。它提高时间覆盖、减轻 Hann 边缘衰减，不改善由窗长决定的 5.859375Hz/bin 分辨率；与 v7 步长无继承关系。Hann 主瓣宽、FTF 不足一周期及 N09 倍频邻带重叠的限制保留，不保证频率干净可分。

以样本索引为时间轴，logspec 中心 `512*i+255.5`，物理中心 `1024*j+1023.5`；同记录内取最近中心，同距取较早 j，首尾取最近的完整物理窗。映射不跨记录、不新增 logspec 窗；并报中心覆盖区外映射数量。约 48,001 点记录：93 个 logspec 窗、45 个物理窗，内部通常两个 logspec 窗共享包络摘要，首尾不固定。

### 3.2 16 维包络特征

两侧逐字相同的流程：整记录四阶 Butterworth 2000–5000Hz 带通（`butter(...,output='sos')`、`sosfiltfilt`）→整记录 Hilbert 包络→2048 分析窗内去均值→`np.hanning(2048)`→rFFT 功率 `P=abs(FFT)**2`。不使用 EEMD，不自适应寻带。

```text
频率维序：BPFO×[1,2,3,4]，BPFI×[1,2,3,4]，BSF×[1,2,3,4]，FTF×[1,2,3,4]
df = 12000/2048
中心 b = floor(f/df + 0.5)
邻带 J = [max(1,b-2), min(1024,b+2)] 的全部整数 bin
noise = median(P[j] | 0 < j*df <= 500Hz)
epsP = max(1e-30, 1e-12*mean(P[1:]))
R(f) = sum(P[J]) / (len(J)*(noise+epsP))
z(f) = log1p(R(f))
```

J 空则报错；DC 永不积分，不对交叠邻带去重或人为拆峰。按实际 len(J) 归一化处理 FTF 边缘截断。常量/全零包络的 R 为 0；检查全部输出有限。此相对比值只近似消除增益，不保证传递路径/噪声域不变。FTF 维解释为低频调制摘要，不是已分辨的 FTF 峰。

### 3.3 九维时域特征与双通道

九项顺序为均值、总体方差、峰峰值、Pearson 峭度、RMS、峰值因子、脉冲因子、波形因子、裕度因子；从原始重采样信号的对应 **512 点窗**计算，不从包络或 2048 窗计算。

令 `m=mean(x),v=mean((x-m)**2),p=max(abs(x)),a=mean(abs(x)),rms=sqrt(mean(x*x)),c=mean(sqrt(abs(x)))**2`。九维为 `[m,v,max(x)-min(x),mean(((x-m)/sqrt(v))**4),rms,p/rms,p/a,rms/a,p/c]`；v=0 时峭度=0，其他比值分母=0 时该比值=0。记录常量窗数量，不删除窗。幅值维仍依赖传感器单位，不宣称它们是不变量。

按中心映射得到 16 维 z，再接上述 9 维，形成与原 logspec 一一对应的 25 维原始物理摘要。每源外层折只在源训练窗口拟合逐维均值/总体标准差，σ=0 则取 1；不裁剪目标异常值，不用源验证或目标统计量拟合缩放。

模型输入固定 `(B,2,256)`：第一通道为原 logspec256，第二通道前 25 位为缩放后的物理摘要，后 231 位补零。补零在缩放之后。logspec-only 对照采用同一个双通道模型，第二通道全部为零。

缓存用原 logspec 子缓存+新增 `phys25.npy` 与普通 JSON 元数据，不永久存重复的 256 维补零通道；训练时组装输入。float32 数组、float64 数值计算；落盘后也检查有限性。版本为 `v8_dual25_12k_512s512_2048s1024_ies_v1`，保存公式/维序/映射及生成脚本版本。旧 logspec 可只读复用或复制，但必须校验其旧配置和记录索引；不得静默复用过期物理缓存。

## 4. GG 新池、共同留出与标签边界

GG 只用 U 的原 **116×256 logspec 单元均值**，完整复用 v7 `unit_level_features` 的窗口权重；不能改用物理特征或记录等权均值。旧池不重算，候选 z-score 仍为 `(x-mean)/(std+1e-12)`，无监督拟合可使用全候选信号，需声明不是信号盲测。

GG 为正则化 Gath-Geva 实现变体，固定：`k=6..19,m=2,seed=0`；KMeans 初始化 `n_init=25`，单线程；200 次上限，`max(abs(U_new-U_old))<=1e-5` 停止。初始化所属簇 U=0.99，其他簇 U=0.01/(k-1)。每次迭代：

```text
v_k = sum_i(u_ik**m*z_i)/sum_i(u_ik**m)
C_k = sum_i(u_ik**m*(z_i-v_k)(z_i-v_k)^T)/sum_i(u_ik**m)
Creg_k = 0.9*C_k + 0.1*I；pi_k = mean_i(u_ik)
ell_ik = 0.5*logdet(Creg_k) - log(pi_k) + 0.5*MahalanobisSquared(z_i,v_k,Creg_k)
u_ik = softmax_k(-ell_ik/(m-1))
XB = sum_ik(u_ik**m*||z_i-v_k||**2)/(116*min_{a!=b}||v_a-v_b||**2)
```

用 Cholesky/线性求解，不直接求矩阵逆或 determinant 后取 log。最后据最终 U 重算中心/协方差/XB。达到迭代上限仍未收敛、非有限、硬分配空簇、簇心最小距离平方≤1e-12 的 k 判无效，记原因；不改参数重试。全部 k 无效则停在选标阶段。

选最小 XB，精确同分取较小 k。硬簇为 argmax U，同分较小簇号。每簇按 Mahalanobis 距离平方、单元键排序；簇轮转顺序沿 v7：非单例在前、再按簇号。先各簇一代表，再逐深度轮转，冻结完整 116 序列，前 19 个为新池。代表是簇中心最近样本，不冒称严格 medoid；兼容字段中 `medoids` 长度为 k，**新池不要求 K19=medoids**。

选标函数不读标签/严重度/损伤来源；池落定才作覆盖诊断，不按 Normal 数量换种子或参数。文件为旧 `selection.json`、新 `selection_gg.json`，再单独生成 `paired_splits.json`：

```text
T_old = U - P_old                                       （97）
T_gg = U - P_gg                                         （97）
T_pair = U - (P_old ∪ P_gg)                              （78+|交集|）
共同未见轴承 = 全部主轴承 - (bearings(P_old) ∪ bearings(P_gg))
```

共同未见组只取 T_pair 内单元；各臂自己的 seen/unseen 另报。池与对应自然留出不重不漏覆盖 U，T_pair 与两池均不交。逐臂 K19 与研究总标签并集数量分开声明；不得用池外标签调参/校准。

## 5. 深度训练、适配与多源接法

固定折 `[0,1,2,3]`、seed `[0,1,2]`、batch=64、epochs=30、Adam 默认 β/ε、无 weight decay/学习率调度，`joint_lr=0.001,adapt_lr=0.0001`。`steps=ceil(本折源训练DE窗口数/64)`，每轮固定 steps，正式使用 `last.pt`；best 只作诊断，不因源或目标分数早停。

源采样完整保留 v7 的通道→类别→记录→记录内窗口均衡、有放回及 `num_samples=steps*64`。目标监督按池内同款有标签均衡，无标签 AdaBN 只均匀窗口采样且不访问真值。种子设置及 sampler 的源 seed/目标 seed+1 沿用 v7；测试 eval/no_grad，不更新 BN。

| 臂 | 初始化 | 梯度/损失/输入 |
| --- | --- | --- |
| `joint` | 同 seed 从头 | CE_source，双通道 |
| `joint_logspec` | 与 joint 同架构同初始权重 | 同 source batch/步数，物理通道恒零 |
| `mixup4src` | 与 joint 同架构同初始权重 | 原 CE + 双 Mixup，lr=joint_lr |
| `coral4src` | 与 joint 同架构同初始权重 | CE_source + 0.2*类条件CORAL，lr=joint_lr |
| `ce_K19/ce_K19_gg/ce_K116` | 同格 joint 的 last | CE_source+CE_pool，各 64 样本/步，lr=adapt_lr |
| `ce_K19_logspec` | 同格 joint_logspec 的 last | 与 ce_K19 同旧池/batch/步数，物理恒零 |
| `adabn` | 同格 joint 的 last | 无优化器，30 轮 BN 重估；Dropout 关闭，BN momentum=0.1、不重置，仅用 U |

所有从头训练臂的源 sampler 独立使用相同 seed；Mixup 的随机数独立 RNG=`seed+10000`，不能改变基座 sampler 序列。ce 池名显式映射，不能用 `removeprefix` 将 `ce_K19_gg` 误解析成预算名。

### 5.1 四来源 Mixup

同一个 64 源 batch 按来源分组，`M=min(四组数量)`；各组独立随机排列后取前 M 个，组成 M 个四元组。不另外读取真实源样本，M=0 时两项混合损失为零并统计次数。每四元组取 `lambda~Dirichlet(1,1,1,1)`。

原 batch 前向取得原 CE 与 attention 后的 256 维嵌入。输入混合 `x'=sum(lambda*x)`；特征混合 `h'=sum(lambda*h)` 后直接调用原 head；二者共用软标签 `y'=sum(lambda*onehot(y))`。软 CE=`mean(-sum(y'*log_softmax(logits)))`，总损失 **CE_raw+0.5*CE_input_mix+0.5*CE_feature_mix**。每步最多多 16 个合成样本的骨干前向，特征混合只走 head；额外计算/BN 影响属于该增强方法，不宣称与 joint FLOPs 相等。

### 5.2 类条件 CORAL

只在三个故障来源间，按共有 B/IR/OR 分别对齐 256 维嵌入；Normal 只走 CE。每项协方差用 n-1 分母，损失 `||C_a-C_b||_F^2/(4*256**2)`，有效来源对×类别等权平均；任一侧不足两样本的项跳过并记覆盖，全部无效返回设备上的零。不是类别齐全四域的边际 CORAL，不接目标信号，不加伪标签或 MMD。

## 6. Normal 单类证据

每个源外层折训练一份 OCSVM，固定 `RBF,nu=0.05,gamma=1/25,tol=1e-3`，只使用本折源训练 Normal 的全部 25 维物理窗口，使用 §3 的源训练缩放；不在 logspec 上拟合，不加入目标 Normal。四折共四份、seed=0，跨深度 seed 复用，非概率模型不套用神经网络 checkpoint 格式。

```text
a(x) = -decision_function(x)                         （大为异常）
t = Q_0.99(a(x) | 本折源验证 Normal 的全部窗口)
s = max(Q_0.75(a_train_Normal)-Q_0.25(a_train_Normal), 1e-6)
r(x) = expit((t-a(x))/s)
q_normal(x) = [r, (1-r)/3, (1-r)/3, (1-r)/3]
```

所有分位数固定 NumPy `method='linear'`；`expit` 用 SciPy 稳定实现。辅助正常判定 `a<=t` 单独报告，不能与融合 argmax 等同。q_normal 先逐窗形成，再按原 logspec 窗口→记录→单元等权聚合。

t 为源验证**窗口**经验分位数，不是目标误报率保证；r 是软证据，不称真实正常后验。每折仅一份源 Normal 验证文件、含两个通道，不能据大量窗口数声称拥有大量独立校准样本。报告目标异常分/证据的分布供事后解释，不利用它重新选 t、s、γ。

产物：`outputs/train/normal_f{f}/` 下模型、缩放参数、`config.json`、`split.json`、`calibration.json`；记录 t/s、训练/验证单元清单与窗口计数。拟合无穷/失败直接停止该折，不自动换模型。

### 7.1 旧完整记录锚

保留原 `phys_envelope` 的四维预测及规则，不在 v8 悄悄改为 SOS、短窗或功率积分。将旧 `predictions.csv`/`unit_predictions.csv` 按记录身份读入，重新计算 §4 的留出/分组指标并写到 v8 `outputs/eval/phys_envelope/`；旧输出只读。记录复用来源与原规则。缺旧预测或覆盖不全时报错，不静默切换到新规则重新生成。

旧锚在完整记录上、5 个谐波、±2Hz 取峰、原带通实现与原判别阈值均保持；它与新锚的信息粒度不同，作为另一个强对照保留，不能仅因“不同窗”删除。

### 7.2 新 IES 锚 `phys_ies`

本轮明确**只做 IES**；LEOC、EEMD、OWES 全部不进入执行链，不安装 EMD-signal。原名 `phys_envelope_v2` 在本计划统一改为 `phys_ies`，避免让输出名暗示完成了三项升级。

使用 §3.2 同一信号处理函数及未映射的 2048/1024 分析窗，每窗算：

```text
e_OR = mean(R(BPFO*h), h=1..4)
e_IR = mean(R(BPFI*h), h=1..4)
若 e_OR > 1.5*e_IR：OR
否则若 e_IR > 1.5*e_OR：IR
否则：Normal
```

每分析窗预测转四维 one-hot，再按分析窗→记录→单元等权平均；同阈值边界/两者全零均判 Normal。不把最近中心映射后的重复摘要再当独立物理窗加权；记录里的 `window_count` 对新锚是物理分析窗数，另存 `logspec_window_count`，二者不混用。

新锚本来就是 N/IR/OR 三类规则，Ball 恒零、P_ball=0 属候选空间限制，不证明跨任务 Ball 拒识。它是零拟合、零标签规则，不以 PU 得分改频带、阈值、谐波或窗长，不把 80% 当作继续训练的成绩门槛。

### 7.3 用于融合的 `q_phys`（不是新锚的硬 one-hot）

为避免三类规则硬零锁死 Ball，对每个原始物理分析窗固定构造：

```text
v = [1, 1, (1+e_IR)/(1.5*(1+e_OR)), (1+e_OR)/(1.5*(1+e_IR))]
q_phys = v/sum(v)
```

加 1 是固定伪计数，非从目标拟合。四项均为正；物理分支没有独立分辨 Normal/Ball 的能力，用相同基准 1 明示未区分，而不是根据“PU 无 Ball”置零。此软分仍有先验/尺度偏差，不称中性后验或通用四类诊断器；源四类验证决定它是否值得融合。

q_phys 先对原始分析窗平均成记录概率，再对记录平均成单元概率。深度/单类/物理使用不同窗口粒度，但**记录和单元身份必须一致**；少一路记录直接报错，不能只在交集样本上融合。

为复用计算，物理特征构建时另存逐分析窗 16 维原始 R 的 `ies_analysis.npy`，JSON 记录各记录的 analysis_start/stop；深度输入仍用 log1p(R) 与中心映射后的 25 维。两个数组共用生成口径、各自区间完整覆盖，不能从补零后的第二通道反推规则分数。

产物：`outputs/eval/phys_ies/` 保存规则、记录/单元预测、e_OR/e_IR 摘要与按配对清单重评分；另保存供融合复用的 q_phys 记录/单元软分。两锚均含 KB 的无真值分析，但不在 KB 上拟合或选规则。

## 8. 晚期融合、消融与不确定报告

每格 `fusion_joint`、`fusion_ce_K19` 复用同折同 seed 的深度末轮预测，源验证及 PU 都必须从同一末轮前向获取。Normal 复用本折一份模型，q_phys 是固定规则。四维证据到单元级后融合：

```text
p_fused = w_D*p_deep + w_N*q_normal + w_P*q_phys
候选 w∈{0,0.25,0.5,0.75,1}^3，和为1，w_D>=0.5
```

共六个候选权重，只在**本折源验证文件单元的四类宏召回**上最大化 E1，包含源 Ball；不优化 PU E2/P_ball。精确同分依次选 w_D 较大、辅助非零支路较少、w_N 较大者，唯一决定一组权重，随 `calibration.json` 落盘。某辅助权重选为零是正式结果，不强行让每个模块有贡献。

每基座并报四个版本：原深度、去物理（D+N）、去单类（D+P）、完整融合。两路版本从已选完整权重中将相应支路置零，再重新归一化；不另调权。w_D≥0.5 保证分母非零；若剩余辅助也为零，两路版本等于深度原始并明确记录。

融合主要发生在单元级；记录级诊断用相同固定权重融合三路记录概率再平均。线性等权保证两条计算路径一致，必须测试，不能再对融合结果做一层额外的样本平均。

各预测器的不确定阈值为 `tau=Q_0.05(max(p_source_val_unit))`，在全部源验证单元上拟合，不按正确/错误筛样本。`max(p_unit)<tau` 仅标记低置信度；不拒判、不改类、不删分母。每个融合消融版本使用自己源验证概率确定 tau，避免借用不同概率尺度；报告源经验覆盖率、目标覆盖率、低置信样本清单与归一化熵 `-sum(p*log(p))/log(4)`（0log0=0）。

主预测中不屏蔽 Ball；自然融合可以改变四类相对得分，但不存在保证 Ball 消失的规则。错误互补表报告两路均对/仅深度对/仅物理对/均错，并列原始 P_ball，不以类召回错位代替逐单元互补证据。

## 9. `svm_phys` 与探索性 RS

### 9.1 拟合规模、权重与内部调参

固定 RBF `SVC(probability=False,decision_function_shape='ovr',tol=1e-3,cache_size=1024,max_iter=-1)`。源训练+旧 K19 联合重拟合，不称微训，不加入新 GG 池、KB 或任何池外 PU 单元。

每单元最多 64 个 512 窗：按排序后的记录键尽量等分配额，余数依序加一，单记录取 `floor((j+0.5)*n/q),j=0..q-1`，不重复/不放回。CWRU 两通道各 32；PU 20 或19记录均参与。若某记录不足配额，先分满它，余量按同序轮转到仍有未取窗口的记录；单元总窗不足64则全部使用，不补样本，并落盘配额。当前固定数据均足够，配额不根据分数扩大。

样本训练权重为“源/目标域各一半→域内有支持类别等权→类内单元等权→单元内已取窗口等权”：

```text
raw_weight(x) = 1/(2 * n_classes_in_domain * n_units_in_domain_class * n_selected_windows_in_unit)
最终 sample_weight = raw_weight/mean(raw_weight)
```

各次拟合按该次可用训练集重算权重。C 网格 `[0.1,1,10]`，γ 网格 `[0.01,0.04,0.1]`。每个外层 fold/seed 用一套 `StratifiedGroupKFold(n_splits=3,shuffle=True,random_state=seed)`，组键 `dataset/unit_key`，候选共用分组；每个内部训练折必须含四类且无单元跨折，否则报错、不换 seed。

调参时，各内部训练折的缩放只用该折**源训练单元的原始全部窗口**拟合，再用于内验证；不能先对完整外层源训练拟合后声称内部验证也完全未见。它是 SVM 内部验证的缩放例外；最终模型才使用 §3 的外层源训练缩放。

候选排序：在三折池外预测中，先对每单元计算已抽样窗口预测正确率，再类等权得到源四类均值与目标池三类均值，二者各一半。它只是内部候选选择准则，不冒充主单元级 E1。精确同分选较小 C、再较小 γ；记录全网格和每折分组。目标 K19 内调参属于获准的19标签预算，但调参预算与固定 CE 配方不同，不能将差异纯归因于 SRM 理论。

### 9.2 显式留出校准，不做窗口随机五折

选定 C/γ 后在完整本折源训练+K19 配额样本拟合一次最终 SVC。**源外层验证不参与 SVC 或 C/γ 内部选择，只作为独立单元留出的概率校准集**；各验证文件的两通道全部窗口都不与 SVC 训练重叠。

使用已安装 sklearn 的 `CalibratedClassifierCV(FrozenEstimator(fitted_svc),method='sigmoid')`，拟合源验证特征/四类标签；类→文件→通道→窗口等权，权重归一到均值1。FrozenEstimator 禁止重拟合 SVC，不触发默认窗口随机 CV。三折用于调 C/γ，独立源验证单元用于概率校准，这是显式分组留出的接法，不是“分组三折 Platt”的混称。

校准仍是相关源窗口上的有限经验拟合，不声称目标后验保证；源验证校准后分数只能作校准诊断，不再声称它是独立源泛化得分。校准器输出按 `classes_` 回填 Normal/Ball/IR/OR，最终对全部评估窗口预测概率并走窗口→记录→单元等权管道。

每 fold/seed 都保留独立模型产物（共12格，seed影响内部分组）。记录 sklearn 版本、配额、拟合次数、耗时、内存、支持向量数；不承诺 CPU RBF 网格秒级，也不把 T4 当成默认 SVM 加速。

### 9.3 RS 探索性分析

只使用旧 K19 的25维物理摘要，先窗口均值成记录、再记录等权成单元；源训练缩放不在目标重拟合。每属性按池内 `[25%,50%,75%]` 分位离散化，重复边界合并，边界相等用 `searchsorted(...,side='right')`，常量属性归一个箱。

在19单元决策表上，正域为属性离散签名相同且标签一致的等价类之并；依赖度 `gamma=正域样本数/19`，属性重要度 `gamma(全25维)-gamma(删该维)`。输出25项与基线依赖度、唯一签名/纯类数、池支持数。仅作探索，不改主输入、不追加约简训练、不检验未输入的共振/散射能量，不将正域偏高等同显著性或因果贡献。
