## 1. 唯一公式

输入使用现有 `outputs/features_v2/` 的未映射 `(A,16)` 原始 IES 分析窗 R，缓存版本必须为 `v8_dual25_12k_512s512_2048s1024_ies_v2`。沿用该缓存既有的分频段噪底、BPFI 边带扩展；本补丁不重算 R、不改频带、窗长、谐波或深度输入。

```text
e_OR = mean(R[:, 0:4], axis=1)
e_IR = mean(R[:, 4:8], axis=1)
c = 0.25                         固定，不扫描、不拟合
r = e_IR / (e_IR + e_OR)          两者全零时 r=0.5
q_phys = [0.25, 0.25, 0.5*r, 0.5*(1-r)]
维序 = Normal / Ball / IR / OR
```

不使用 alpha、健康基线、softmax 或固定 epsilon 改变非零能量的比例。实现可采用等价的缩放除法避免溢出。所有输入必须为非空、有限、非负实数 `(A,16)`；输出有限、非负、和为 1。允许某个类型项在该类型能量恰为零时为零；Normal/Ball 始终为 0.25，不对 Ball 作硬屏蔽。

先逐分析窗生成 q，再在记录内等权平均，最后在单元内按记录等权平均；不先平均能量再取比值，不重复计入中心映射窗。四类 argmax 同分沿既有类序取最前者。KB 仅输出分布，不计有真值的命中率。

## 2. 选择依据与不能声称的结论

在 `q(c)=[c,c,(1-2c)r,(1-2c)(1-r)]` 这族公式中，c=0.25 是 r=0.5 时得到四类均匀分布的唯一取值：

```text
q_phys = [0.25, 0.25, 0.25+delta, 0.25-delta]
delta = 0.5*(r-0.5)
```

因此可解释为“均匀中性基准 + IR/OR 间的份额转移”。它消除了无类型差异时固定的故障偏置，但均匀基准不是经证明的真实类别先验，也不证明最优校准。

历史扫描在 c=0.05～0.25 的记录级命中率相同：CWRU IR/OR 约 98.6%/75.3%，PU IR/OR 约 82.3%/87.9%，两域 Normal 均为 0%。该平台主要是 argmax 的公式性质，不作为融合最优性或独立泛化证据；扫描未报告的源域 Ball 在本轮补查。c=0.25 不再根据后续 PU 表现调整。

不得使用“最优平衡”“零添乱”“信息论保证安全”或“最大熵证明最优”等表述。不宣称 IR 故障检出已解决，也不从若干方法失败推出原信号不存在任何 IR 信息或 LEOC/谱相干必然无效。

## 3. Normal 与融合边界

q_phys 不区分 Normal 与 Ball，也不独立检测是否故障。r 偏离 0.5 可能来自类型信息，也可能来自噪声或传递路径偏差；即使两个能量都很小，比值也可能偏向一类。

对单条正常记录或正常单元，推力定义为 `max(q_B,q_IR,q_OR)-q_N`，在本配方下等于 `abs(delta)`，数学上界为 0.25。若物理权重为 0.25，其对故障类相对 Normal 的贡献上界为 0.0625。必须分别报告逐记录和逐单元推力的均值、中位数、95% 分位数和最大值，不能用类平均软分的最大项代替平均逐样本推力。

正式融合仍是加权算术融合，OCSVM 不是硬门控；不能保证它覆盖物理误导。若以后显式批准接入该探索配方，仍只按同折源验证单元的四类宏召回选权，包含 Ball，允许 w_P=0；网格、同分规则和 without_phys/without_normal 消融不变。真正净收益须由同一基座、同一清单的配对融合结果验证，当前没有 P5 深度概率，不能作收益判断。
