# P1 本地接口约定

只服务阶段三固定矩阵，不构造通用框架。工作根为 v8，v6/v7 只读；本轮不执行真实数据拟合与全量缓存。

- `FeatureCache.X` 保持原 `(N,1,256)` logspec，新增 `.phys25` `(N,25)` 原始摘要与 `.ies_analysis` `(A,16)` 原始 R；records 仍有 start/stop，增加 analysis_start/analysis_stop。`feature_subset` 保留上述属性并重排 logspec 区间，分析窗可通过 `analysis_ranges` 引用共享全量数组，返回 `.y`、`.records`、`.X`、`.phys25`。
- `features.fit_scaler(phys25)` 返回含 `mean`、`std` 列表的普通字典；`features.scale_phys(phys25, scaler)` 返回缩放数组；`features.dual_input(X, phys25, scaler, logspec_only=False)` 返回 `(N,2,256)` float32，第二通道先缩放再补零。训练用数据集逐 batch 组装，勿永久缓存补零通道。
- `model.MSRSABiLSTM(n_channels=2, n_classes=4)` 保持原网络、四类头及 `return_feat=True` 接口。
- `selection.load_selection(path)` 读取普通 JSON；旧/新池都保持 `budgets.K19.pool/test`、`budgets.K116.pool/test`；配对文件字段 `U/P_old/P_gg/T_old/T_gg/T_pair/common_unseen_bearings/common_unseen_units`。
- IES 信号核心放在 features：`ies_features(signal_12k, orders, rotation_hz)` 返回 `(A,16)` 原始 R；`physical_baseline.ies_evidence(R)` 返回 `(hard_onehot, q_phys, e_ir, e_or)`。
- `evaluate.aggregate_records`、`aggregate_units` 保持 v7 字段；`evaluate.save_reports` 保持原参数并接受额外配对/不确定信息。新增 `evaluate.read_predictions(path, unit=False)` 将 CSV 转回带 probabilities 的普通行字典。
- `oneclass.fit_normal(source_cache, fold, output, config)`、`oneclass.predict_records(cache, model_dir)`：前者拟合本折 Normal，后者返回记录概率；`shallow.fit_shallow(source_cache,target_cache,selection,fold,seed,output,config)` 与 `shallow.predict_records(cache,model_dir)` 同型。
- 所有入口默认 `configs/stage3.json`，只在 `--execute` 下执行实际准备/拟合；dry-run 不构造模型。配置键兼容 v7 核心键，新增配方块；各模块缺关键依赖必须报错。

实施时若旧接口不适配，先明确告知主代理与其他调用方；不要写猜测式兼容层。
